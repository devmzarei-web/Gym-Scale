# Contract: PDF Export Endpoints & Print Preview Fallback

## 1. Routine PDF Export Endpoint

- **Endpoint**: `GET /api/routines/{id}/pdf`
- **Query Parameters**:
  - `clientId` (optional, string): ID of client assigned to routine for metadata personalization.

### Success Response (Direct Stream)
- **Status**: `200 OK`
- **Headers**:
  - `Content-Type`: `application/pdf`
  - `Content-Disposition`: `attachment; filename="NutriTrain.ir-{trainer}-{client}-{date}.pdf"; filename*=UTF-8''...`
- **Body**: Binary PDF buffer generated by headless Chromium.

### Resilient Fallback Response (Server Limiting / Engine Exception)
- **Condition**: Puppeteer engine timeout, resource constraint, or missing container graphics libraries.
- **Status**: `307 Temporary Redirect`
- **Headers**:
  - `Location`: `/routines/{id}/pdf?clientId={clientId}&autoPrint=true`
- **Client Behavior**: Browser seamlessly follows redirect to the printable preview page and immediately invokes `window.print()` using native client-side PDF rendering.

## 2. Diet PDF Export Endpoint

- **Endpoint**: `GET /api/diets/{id}/pdf`
- **Query Parameters**:
  - `clientId` (optional, string): ID of client assigned to diet for metadata personalization.

### Success Response (Direct Stream)
- **Status**: `200 OK`
- **Headers**:
  - `Content-Type`: `application/pdf`
  - `Content-Disposition`: `attachment; filename="NutriTrain.ir-Diet-{trainer}-{client}-{date}.pdf"`
- **Body**: Binary PDF buffer.

### Resilient Fallback Response
- **Status**: `307 Temporary Redirect`
- **Headers**:
  - `Location`: `/diets/{id}/pdf?clientId={clientId}&autoPrint=true`

---

## 3. Printable Preview Routes Contract

- **Routes**: `/routines/{id}/pdf` and `/diets/{id}/pdf`
- **Query Parameters**:
  - `clientId` (optional): Client metadata injection.
  - `autoPrint` (optional, boolean): If `true`, client-side effect executes `window.print()` after document hydration.
- **Header Action Bar**:
  - Hidden during print (`@media print { .no-print { display: none !important; } }`).
  - Contains manual "چاپ و ذخیره PDF" trigger button.
